## [0.1.0] - 2026-08-23

### Summary

This is the one consolidated campaign source release for the 4PDA connector. It keeps the full public method boundary, source policy, schemas, evidence/search/graph/query/answer contracts, fixtures, evals, owner-local KAG/stats ports, generated consumer family, and explicit readiness/ownership limits from the same-day release history. The exact landed source is the current main lineage at consolidation time; publication carriers are not additional product versions.

The active provider identities are exact: `aoa-kag@v0.5.0` tag object `8f63e3ae558ea96d21ee06becfa6ef61d63d698a` peels to `f46f146cc79a26fa81ad0f400b9c5774df293e57`; direct `aoa-stats@v0.2.2` tag object `119f434918e8218e43e977b2edec3e4feab6b493` peels to `f119805cda69b3edeb2a4c5e407368d70e68650d`.

### Added

- Consolidated the four same-day Release bodies and tag-scoped changelog snapshots into this single dated section; the task-local ledger records every input line, source hash, and canonical mapping.
- Preserved the connector's bounded Python package and CLI, public-only 4PDA source policy, normalized topic/post and evidence packet schemas, search/chunk/index/vector/graph/query/answer surfaces, focused profiles, fixtures, eval routes, install/doctor routes, local stats port, and owner-local KAG family.
- Preserved the complete historical first-parent and merged-PR reconciliation, including direct landings, provider corrections, generated-family migrations, budget receipts, and release-carrier evidence.

### Changed

- Rebound version-bearing source surfaces to `0.1.0` and the workflow/release checker to the exact final provider identities above.
- The owner release law now describes one consolidated campaign release and the exact `aoa-kag@v0.5.0` action/family identity while retaining prior provider identities as historical material.
- Regenerated consumer-visible KAG indexes from the owner generator route after the authored tree change; generated records remain derived and subordinate to authored source.

### Fixed

- Removed release churn as a public state problem by making the final publication route delete only the four pretruth-listed same-day carriers after landed-main gates and recreate only `v0.1.0`.
- Retained exact provider equality checks, source-only posture, and the distinction between publication evidence and artifact/runtime/proof/acceptance claims.

### Deprecated

- No authored connector API, source-policy route, schema, answer field, or runtime ownership boundary is deprecated by this consolidation.
- Superseded same-day Release/tag carriers are historical publication records, not additional product versions; their content remains in the ledger and historical blocks below.

### Removed

- No source capability or material contract was removed. Only the exact pretruth-listed same-day GitHub Release and tag carriers are eligible for post-merge cleanup; raw reports, source history, and ledger evidence are preserved.

### Security

- Public topic/post allowlisting, network-off-by-default behavior, read-only local/MCP boundaries, and denial of private routes, authentication, attachments, downloads, uncontrolled discovery, secrets, and private corpus material remain unchanged.
- No secret, credential, private capture, or authenticated route is included or published.

### Compatibility and migration

- Consumers must use the exact active provider pins and the portable KAG family manifest/shards/validator. Ancestor-only provider checks are insufficient.
- Historical `aoa-stats@v0.2.0`, `v0.2.1`, and historical `aoa-kag@v0.5.2` identities remain represented in the ledger and historical source blocks; they are not active bindings for the consolidated release.
- This remains a 0.x source/method boundary. Runtime consumers must follow the `abyss-stack` adapter contract and must not infer deployment or health from local receipts.

### Deployment, observability, recovery, and rollback

- This source-only release performs no deployment or runtime activation. `abyss-stack` owns deployment/MCP access; `aoa-kag` owns shared KAG validation; `aoa-stats` owns shared measurement grammar; central proof and acceptance remain with their owners.
- Doctor, storage, readiness, freshness, coverage, discovery/review, packet, and validation receipts expose bounded evidence only. The release publisher refuses force-tagging/overwrite; cleanup is limited to the exact same-day carriers named by pretruth.

### Validation

- Required source gates are the owner release-surface preflight, connector validator, local stats-port validator, pytest, compileall, and no-network CLI routes; the PR and landed-main hosted checks are recorded in the final execution report.
- The KAG portable-family check and owner validator are run from the pinned provider route; generated-family deltas are covered by an explicit owner budget receipt where required.
- `connector-ready-v1` remains `not_ready`/`ready=false`: no coherent fresh crawl-to-derived-artifact chain is claimed. Existing test, schema, validator, eval, and readiness evidence is preserved without promoting it to runtime or semantic proof.

### Notes

- This release has no public package assets and no connector-owned artifact-policy class or attestation. GitHub publication is source publication evidence, not trusted artifact admission.
- The provider handoff was accepted using its explicit recovery-closure evidence because its canonical closure file is absent; the final report records that evidence boundary and does not upgrade it into artifact, runtime, proof, delivery, closure, or acceptance.
- No human/owner acceptance is inferred from source, CI, GitHub Release, tag, generated indexes, or this changelog.
